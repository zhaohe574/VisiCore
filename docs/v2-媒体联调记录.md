## 已修复问题

1. 带 `+08:00` 的回放和导出时间入库触发 Npgsql 错误。接口入库参数转换为 UTC，保留实际时刻；导出专用真实数据库回归 4 项通过。
2. 回放原队列 256 个条目在约 5 MB 时就可能耗尽，早于 16 MB 字节上限。当前保留 16 MB 限制，最大条目为 4096，同时按字节和条目数控制高低水位，仍由独立状态巡检发送 SDK 暂停／继续。溢出时明确失败，不静默丢弃压缩帧。
3. 海康 `IMKH` 文件前导及不完整 PS 数据导致 FFmpeg 无法取得尺寸。仅对匹配 `IMKH` 的文件寻找首个 MPEG-PS 包，规范化后封装 MP4；其他容器不截断。复制、封装和打包期间持续检查磁盘容量，错误输出最多保留 16 KB 并隐藏媒体地址及凭据。
4. 新增鉴权 HTTPS MPEG-TS 地址 `httpTsUrl`，提供 H.264/H.265 原码流给桌面播放器；保留 HTTP-FLV 供 Web 使用。Nginx 仅开放指定媒体路径，仍执行 ZLMediaKit 播放鉴权。未使用的 HLS 文件生成功能关闭。
