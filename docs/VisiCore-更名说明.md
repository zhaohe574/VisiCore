# VisiCore（视枢）更名说明

2026-09-08，项目统一使用英文名 **VisiCore**、中文名 **视枢**，仓库地址为 `https://github.com/zhaohe574/VisiCore`。

## 更新范围

Web 页面、路由标题、导航、登录页、下载首页、站点图标，桌面主窗口、登录视图、消息框、更新器、程序集产品信息，MSI 产品名称及安装向导，服务描述、OpenAPI 标题与项目文档均使用新品牌。Web 标识源文件为 `web-admin/public/visicore.svg`；桌面位图与 ICO 由 `tools/create-desktop-assets.py` 以相同造型、配色生成。

主解决方案入口为 `VisiCore.slnx`。原 `VideoPlatform.sln` 保留供第一版历史构建记录定位，新开发使用新版入口。

## 保留的兼容标识

| 标识 | 保留原因 |
| --- | --- |
| `VideoPlatform.*` 源目录、程序集和命名空间 | 避免更名改变生成客户端、可执行文件定位及项目引用。 |
| `VideoPlatform.Desktop.exe`、`VideoPlatform.Updater.exe` | 保持已发布更新链路和 MSI 文件标识一致。 |
| MSI UpgradeCode、注册表路径、安装目录 | 让后续品牌版本能识别已有安装并正常升级。 |
| `LocalAppData/VideoPlatform`、DPAPI 附加数据、Cookie 名称 | 保留已有配置和登录数据的读取边界。 |
| `video-platform*` 服务、数据库、部署目录、环境变量和健康标识 | 避免产品改名改变现有部署、运维脚本和健康检查契约。 |

服务端平台基线为 2.0.0、桌面已发布基线为 2.0.1，本次品牌改动记为未发布源码变更。现有线上包、版本记录和真实验收证据不会被重新命名或改写成品牌新版已经验收。

## 仓库整理

源码、数据库迁移、构建定义、测试用例及中文说明进入仓库。忽略构建输出、备份、日志、原始测试截图、认证配置、私钥及专有 SDK；历史实机报告保留日期和未通过事项。公开下载页的历史界面图明确标注更名前截图，不作为本次视觉验收证明。

当前工作目录名不参与产品身份，开发者可将仓库克隆到任意目录。不要为重命名而修改生产数据库、摄像机参数、证书私钥或用户密码。
