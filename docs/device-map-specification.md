# PC Web 终端边界说明

VisiCore 管理 Web 仅面向内网 PC 浏览器。业务页面、登录会话、实时媒体和管理操作都要求桌面 User-Agent；手机浏览器由前端入口和 Nginx 统一拦截，并返回 `desktop-only.html` 提示页。

PC 窄窗口仍使用普通桌面布局，允许页面滚动，最小可用宽度由业务表格和视频工作区决定。该布局不包含移动菜单、移动导航、触控专用操作或 `/m` 业务路由。

验收应覆盖桌面 User-Agent 的首页、登录、`/app` 深链接和业务 API，以及 Android／iPhone User-Agent 的提示页或 403 响应。手机请求不得触发业务脚本、会话读取或媒体请求。
