## 问题与恢复来源

此前基线清理把尚未提交的业务功能一并删除，导致电脑登记、ONU 台账、终端箱等页面、接口和数据模型缺失。这些功能属于现行业务，应当保留。

## 合并修正

- 保持 PC-only 策略：删除恢复代码带入的移动菜单、遮罩、移动状态和断点样式，保留手机提示页及 Nginx 拦截，P2P 服务继续停用。
- API 继续使用 `/api/v2`，分页统一为 `PagedResponse<T>`。重新生成 TypeScript 和 C# 客户端，生成结果与纳入源码的文件一致。
- 通道查询只返回是否配置密码，编辑时密码输入初始为空，支持显式清除；详情不回显密码。
- eSight 连接信息从已登记且启用的设备配置解密加载，删除硬编码默认密码。
- 修正收藏查询的通道关联、新增字段的接口元数据以及 WPF 筛选参数调用。
- Web 业务请求收到 401 后立即退出，不自动重放；主动并发续期仍合并为一次请求。
- API 健康检查和 Worker 心跳读取真实程序集版本。桌面安装包未重新发布，适配器使用切换前的正式版本。
