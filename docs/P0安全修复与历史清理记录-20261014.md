| 项 | 文件 | 说明 |
| :--- | :--- | :--- |
| TLS 校验 | `TlsTrust.cs`（新增） | 默认走系统信任链；仅当登记 `PLATFORM_TRUSTED_CERT_SHA256` 时才放行匹配指纹的自签名证书 |

| 凭据解密 | `Security.cs` | 密文解密失败不再返回密文，抛明确业务错误；仅历史明文（无 `CfDJ8` 前缀）按明文兼容并告警 |
| 私钥权限 | `SslService.cs` | 落盘后收紧为 `0600` |
| 测试崩溃 | `VideoPlatform.Adapter.Tests/Program.cs` | 修复"分配 1 字节却声称 17 MB"导致的**原生访问违例**（0xC0000005）；并使溢出用例真正超过 64 MB 上限 |
| 测试退出码 | `VideoPlatform.IntegrationTests/Program.cs` | 环境缺失时输出 `SKIP` 并返回 0，不再抛未处理异常 |

### 关于 Adapter.Tests 的原生崩溃

该用例原本会以 `0xC0000005`（访问违例）终止进程，**在原始提交上同样复现**，
属既有缺陷而非本次引入。原因是 `Marshal.AllocHGlobal(1)` 分配 1 字节，
却以 17 MB 大小调用 `Marshal.Copy` —— 越界读取导致原生崩溃，
`catch` 无法拦截。且 17 MB 小于 64 MB 缓冲上限，测试意图的"溢出失败"分支
从未被执行。现已修正为声称 65 MB（超过上限，在拷贝前即被拒绝）。
