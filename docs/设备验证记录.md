# DS-A72124R 实机验证记录

## 设备

| 项目 | 结果 |
|---|---|
| 设备地址 | `10.37.200.53` |
| 型号 | `DS-A72124R` |
| 序列号 | `DS-A72124RFT0116118` |

| SDK | 设备网络 SDK_Linux64 V6.1.11.30 |
| 服务器 | Ubuntu 26.04 LTS、x86_64 |

## 已验证

- HCNetSDK 原生库及 `HCNetSDKCom` 在 Ubuntu 26.04 可加载。
- `NET_DVR_Login_V40` 登录成功。
- SDK 设备摘要返回数字通道能力 1024、1 个硬盘、支持 RTSP。
- HCNetSDK `NET_DVR_GET_IPPARACFG_V40` 可读取前 64 条配置。
- 设备 ISAPI `GET /ISAPI/ContentMgmt/InputProxy/channels` 返回完整 81 条通道清单，包含名称、在线状态和型号。
- 通道 1 使用子码流预览 5 秒：Python 探针收到 140 个回调、150360 字节；C# 探针收到相同类型码流回调。
- 通道 81 使用子码流预览 5 秒：C# 探针收到 327 个回调、318960 字节。
- 通道 8（`DS-2DC4220IW-D`）PTZ 停止命令成功；左转开始后 1 秒发送停止命令成功。
- `NET_DVR_SetupAlarmChan_V41` 实机布防成功，回调原始报文进入适配服务异步队列。
- 通道 8 按时间回放实机成功，回放会话收到约 10 MB 码流并写入服务器临时 `.ps` 文件；暂停、恢复、进度查询和停止控制成功。

## 实现结论

适配服务优先用 HCNetSDK 完成登录和媒体控制，用 ISAPI 完成 CVR 大容量通道清单同步；这样避免把 `NET_DVR_IPPARACFG_V40` 的 64 条结构上限误当作设备实际通道数。客户端和平台只接收标准化通道信息，不接收设备账号、密码或源 RTSP 地址。
