# VisiCore（视枢）开发文档

## 1．文档信息

| 项目 | 内容 |
|---|---|
| 文档版本 | 1.1 |
| 编写日期 | 2026-09-03 |
| 目标设备 | 海康威视 DS-A72124R |
| 目标平台 | Linux Server、Windows 桌面端 |
| 文档状态 | 开发基线 |

本项目不复用 `gbvr-iot` 的 PHP 代码，仅参考其模块划分、ZLMediaKit 管理方式和视频平台页面组织方式。

## 2．项目目标

建设一个以 DS-A72124R 为中心的视频管理平台：

- 摄像头只添加到录像机，平台不重复添加摄像头。
- 桌面端支持多路实时预览和多路录像回放。
- 支持约 700～800 个平台账号。
- 支持几十到上百个账号同时登录和观看。
- 支持账号、角色、功能权限和通道权限控制。
- 支持车间、区域、机组三层业务结构。
- 通道可以分配到机组。
- 接收录像机和摄像头可配置的报警事件。
- 支持云台控制，并记录操作审计。
- 提供系统信息统计、设备统计和桌面端版本管理。

## 3．首期边界

首期只接入一台 DS-A72124R，但数据模型保留多设备字段，后续可以扩展到多台录像机。

首期不建设以下功能：

- 移动端。
- 域账号、LDAP 或单点登录。
- GB28181 SIP 网关。
- 云端录像存储和录像转码。
- 帧级多路回放同步。
- 服务集群和跨机房容灾。

## 4．技术选型

| 层级 | 技术 |
|---|---|
| 管理后台 | Vue 3、TypeScript、Element Plus、Vite |
| 平台服务 | ASP.NET Core 8 Web API、SignalR |
| 设备适配服务 | C#、.NET 8 Worker Service（Linux x64） |
| 桌面端 | Windows WPF、.NET 8、MVVM |
| 海康接入 | 设备网络SDK_Linux64 V6.1.11.30（HCNetSDK） |
| 流媒体 | ZLMediaKit |
| 数据库 | PostgreSQL 16；开发环境可使用 SQLite WAL |
| 日志 | Serilog，按服务和日期滚动 |
| 部署 | systemd、Nginx、ZLMediaKit 服务 |

### 4.1 选型原则

- 海康设备操作统一封装在 C# 设备适配服务中。
- 平台服务不直接依赖海康原生 DLL。
- 桌面端不保存录像机账号和密码。
- 实时预览优先使用 ZLMediaKit 复用和分发。
- 服务端不默认转码，只有设备码流无法兼容时才增加转码链路。

### 4.2 Linux SDK 运行约束

- C# 海康适配服务运行在 Linux x64，使用 `设备网络SDK_Linux64 V6.1.11.30` 提供的原生 `.so` 库。
- 服务端不使用依赖图形窗口的渲染接口，统一使用实时码流和回放数据回调，再交给 ZLMediaKit 或平台内部媒体链路处理。
- SDK 原生库及其依赖放在应用专用目录，具体库文件名以 SDK 发布包为准。
- 通过 `LD_LIBRARY_PATH` 或应用运行时库搜索路径加载原生库，禁止依赖开发机上的全局库文件。
- 适配服务使用专用 Linux 用户运行，不使用 root 权限。
- 启动时检查 CPU 架构、动态库依赖、读写目录和 SDK 初始化结果，失败时输出明确中文错误日志。
- SDK 回调线程只负责复制数据和入队，不能直接执行数据库写入或阻塞式网络操作。

## 6．服务职责

### 6.1 ASP.NET Core 平台服务

- 本地账号登录、密码修改、锁定和会话管理。
- 角色、功能权限和通道数据权限。
- 车间、区域、机组和通道业务关系。
- 调用海康适配服务的设备操作接口。
- 生成实时预览和回放的临时播放令牌。
- 通过 SignalR 推送报警和设备状态。
- 系统统计、设备统计和审计日志。
- 桌面端版本检查和升级包管理。

### 6.2 C# 海康适配服务

- 初始化和清理 HCNetSDK。
- 使用专用设备账号登录 DS-A72124R。
- 同步录像机和通道信息。
- 创建和关闭实时预览句柄。
- 查询录像文件，创建和控制回放句柄。
- 接收报警回调并标准化事件。
- 执行 PTZ 开始、停止、速度和预置位命令。
- 定时采集设备、硬盘和通道状态。
- 设备断线重连，重连后恢复报警布防。

### 6.3 ZLMediaKit

- 拉取或接收海康实时码流。
- 对相同通道和码流类型进行上游复用。
- 向多个桌面客户端分发实时流。
- 提供 RTSP、HTTP-FLV 或 WebRTC 输出。
- 提供流在线状态、观看人数和码率统计。
- 通过播放鉴权回调向平台服务确认用户和通道权限。

## 7．设备接入方案

### 7.1 设备配置原则

摄像头全部配置在 DS-A72124R，平台只保存以下信息：

- 录像机设备标识。
- 录像机 IP、服务端口和设备型号。
- 录像机通道号、名称、状态和能力。
- 通道对应的车间、区域和机组。
- 通道是否支持 PTZ。

录像机专用账号只保存在 C# 海康适配服务的受保护配置中，不下发到浏览器或桌面端。

### 7.2 通道同步

适配服务启动或设备配置变化时同步：

1. 设备信息和序列号。
2. 模拟通道和 IP 通道。
3. 通道名称、通道号和在线状态。
4. PTZ 能力。
5. 当前录像、视频丢失和报警状态。

新通道进入“未分配通道”，由后台管理员分配到机组。设备移除的通道标记为停用，不物理删除历史记录。

## 8．权限模型

采用 RBAC（基于角色的访问控制）和通道数据范围控制。

```text
有效权限 = 账号所属角色权限的并集
         ∩ 账号允许的数据范围
         ∩ 请求通道所属业务范围
```

默认拒绝，所有设备操作都必须在服务端鉴权，不能只依靠界面隐藏。

### 8.1 功能权限

- `user.read`、`user.manage`。
- `role.read`、`role.manage`。
- `area.read`、`area.manage`。
- `channel.read`、`channel.assign`。
- `live.view`。
- `playback.view`。
- `ptz.control`。
- `alarm.read`、`alarm.ack`。
- `device.read`、`device.manage`。
- `statistics.read`。
- `desktop.release.manage`。

### 8.2 通道操作权限

实时预览、录像回放、云台控制和报警查看分别授权，不能用“能看实时视频”推导出其他权限。

权限撤销后：

- 新请求立即返回 `403`。
- 已建立的媒体会话立即停止。
- PTZ 控制立即发送停止命令。
- 已连接的客户端不再收到该通道报警。

## 9．业务区域模型

固定业务层级：

```text
车间
└─ 区域
   └─ 机组
      └─ 通道
```

规则：

- 车间下可以有多个区域。
- 区域只能属于一个车间。
- 机组只能属于一个区域。
- 通道只能属于一个机组。
- 移动机组或通道时必须记录审计日志。
- 车间、区域、机组支持物理删除，但存在子级、已分配通道或数据范围引用时拒绝删除，不执行级联删除；设备同步移除的通道仍保留并标记停用。

## 10．实时预览

### 10.1 复用策略

实时流唯一键为：

```text
设备 + 通道 + 码流类型
```

同一通道、同一码流类型只从录像机建立一个上游流，多个用户共享 ZLMediaKit 的下游分发。

```text
DS-A72124R ── 一路上游流 ──> ZLMediaKit ──> 多个桌面端
```

100 个用户观看同一路通道时，录像机不建立 100 路重复上游连接。

### 10.2 桌面端功能

- 1、4、9、16 分屏。
- 通道树按车间、区域、机组展示。
- 双击放大和恢复分屏。
- 子码流和主码流切换。
- 单窗口抓图。
- 全屏和退出全屏。
- 断线重连和黑屏错误提示。
- 显示通道名称、在线状态和报警标记。

多路预览默认使用子码流，单窗口放大时允许切换主码流。具体码流类型和 H.265 支持情况以实机验证结果为准。

## 11．多路录像回放

### 11.1 回放模型

每一个不同的通道、时间范围、倍速和播放进度对应一个独立回放会话。

- 支持多个窗口同时回放。
- 支持按通道和时间范围查询录像。
- 支持播放、暂停、停止、拖动和倍速。
- 同一批窗口可以使用统一开始时间。
- 首期只保证时间点基本一致，不做帧级同步。
- 不同用户的回放默认不共享，以保证控制互不影响。

### 11.2 回放链路

```text
桌面端请求回放
→ 平台服务校验通道权限
→ C# 适配服务调用 HCNetSDK 查询和回放
→ 回放流发布到 ZLMediaKit 临时流
→ 桌面端使用临时播放令牌观看
```

相同录像时间段的回放共享属于后续优化，不作为首期依赖。回放并发数根据 DS-A72124R 实测资源限制配置。

## 12．报警中心

### 12.1 接收范围

接收录像机和摄像头当前配置并上报的全部报警类型，包括但不限于：

- 移动侦测。
- 视频丢失。
- 视频遮挡。
- 越界和区域入侵。
- 人员、车辆和其他智能事件。
- 报警输入和报警输出。
- 硬盘、存储和录像异常。
- 设备离线、网络异常和系统异常。

实际事件清单必须根据 DS-A72124R 固件和接入摄像头逐项触发确认。

### 12.2 SDK 方案

优先使用：

- `NET_DVR_SetupAlarmChan_V41`。
- `NET_DVR_SetDVRMessageCallBack_V31` 或设备支持的更高版本回调。
- `NET_DVR_SetExceptionCallBack_V30` 接收设备异常。

报警回调只做快速解析和入队，不在 SDK 回调线程中执行数据库慢操作。每条报警保存标准字段和原始报文，无法识别的新事件不能丢弃。

### 12.3 报警页面

- 实时报警列表。
- 历史报警查询。
- 按车间、区域、机组、通道、设备和类型筛选。
- 报警确认、处理状态和处理备注。
- 报警跳转到实时预览或录像回放。
- 按用户通道权限过滤。
- 报警去重和恢复事件关联。

## 13．云台控制

服务端调用海康 SDK 的通道级 PTZ 接口：

- `NET_DVR_PTZControlWithSpeed_Other`。
- 支持上、下、左、右、自动旋转。
- 支持变倍、聚焦和光圈。
- 支持预置位调用，预置位管理作为第二阶段功能。

安全规则：

- 鼠标按下发送开始命令。
- 鼠标松开立即发送停止命令。
- 客户端失焦、断线或超时自动停止。
- PTZ 操作必须通过服务端鉴权。
- 记录账号、设备、通道、命令、速度和时间。

## 14．管理后台

### 14.1 系统信息统计

- 用户总数、启用数和锁定数。
- 角色数量。
- 车间、区域、机组和通道数量。
- 当前登录人数。
- 当前实时预览人数和路数。
- 当前回放人数和路数。
- 今日报警数和未确认报警数。
- 平台服务、适配服务和 ZLMediaKit 状态。

### 14.2 设备统计

- 录像机在线状态和最后心跳。
- 设备型号、序列号和固件版本。
- CPU、内存和整体工作状态。
- 硬盘数量、状态和容量。
- 通道在线、视频丢失和录像状态。
- 当前实时预览句柄数。
- 当前回放句柄数。
- ZLMediaKit 上游流数量、观看人数和出口码率。

### 14.3 业务区域页面

- 车间列表和编辑。
- 区域列表和编辑。
- 机组列表和编辑。
- 通道分配和批量移动。
- 未分配通道。
- 按业务树筛选通道、报警和统计数据。

### 14.4 账号和角色页面

- 账号新增、编辑、停用和锁定。
- 密码重置。
- 角色分配。
- 功能权限配置。
- 车间、区域、机组和通道范围配置。
- 登录日志和操作审计。

### 14.5 桌面端版本管理页面

- 上传 Windows 安装包。
- 版本号、发布时间和更新说明。
- 设置最新版本。
- 设置最低支持版本。
- 强制更新开关。
- 发布、撤回和停用版本。
- 安装包 SHA-256 校验值。
- 当前客户端版本统计和下载次数。

生产环境应对安装包进行 Windows 代码签名。SHA-256 用于完整性校验，不能替代数字签名。

## 17．媒体鉴权和安全

- 平台使用本地账号，不依赖域账号。
- 密码使用 ASP.NET Core Identity 的安全哈希器保存。
- Access Token 短时有效，Refresh Token 可撤销。
- ZLMediaKit 管理接口只允许内网访问。
- ZLMediaKit 播放请求通过 `on_play` 回调向平台服务鉴权。
- 播放令牌绑定用户、通道、类型、参数和过期时间。
- 客户端不能直接访问录像机管理端口、RTSP 源地址和 SDK 凭据。
- 设备账号使用最小必要权限。
- 所有 PTZ、报警处理、权限变更和版本发布写入审计日志。
- 管理后台和桌面端全部使用 HTTPS。
- 安装包发布目录禁止执行上传文件，文件名使用服务端生成的随机名称。

## 18．并发和容量设计

### 18.1 登录并发

目标为 100 个客户端同时登录。账号、权限和通道树查询属于轻量 API 请求，单服务器即可满足。

### 18.2 实时预览并发

实时预览采用上游复用。容量主要由以下因素决定：

- 同时观看的不同通道数量。
- 每路码率。
- ZLMediaKit 出口带宽。
- 桌面客户端解码能力。
- 录像机实际实时预览上限。

示例：100 个客户端观看同一路 1 Mbps 子码流，录像机侧约为 1 路上游，服务器出口约为 100 Mbps，另加协议开销。

### 18.3 回放并发

不同回放时间线默认独立占用录像机回放资源。服务端必须设置：

- 单用户最大回放窗口数。
- 全局最大回放会话数。
- 单设备最大回放会话数。
- 超限时的排队或拒绝策略。

这些值在设备验证阶段通过 `NET_DVR_GetSDKState`、`NET_DVR_GetSDKAbility` 和实测确定。

## 19．部署建议

首期服务器基线：

- Linux Server，建议 Ubuntu Server 22.04 或 24.04 LTS，最终以 Linux64 SDK 兼容性测试结果为准。
- 8 个逻辑 CPU。
- 16 GB 内存。
- 1 Gbps 网卡。
- SSD 保存数据库、日志和安装包。
- 服务器与 DS-A72124R 位于同一局域网或稳定 VPN。

服务进程：

```text
VideoPlatform.Api      ASP.NET Core 平台服务
Hikvision.Adapter      Linux x64 C# 海康设备适配服务
ZLMediaKit              Linux 实时流媒体服务
PostgreSQL              业务数据库
Nginx                   HTTPS、管理后台和 API 反向代理
```

所有进程使用 systemd 托管并设置自动重启、启动顺序和资源限制。录像机和 ZLMediaKit 管理端口不直接暴露到公网，服务器防火墙只开放平台 API、SignalR 和必要的媒体播放端口。

### 19.1 Linux 目录建议

```text
/opt/video-platform/
├─ api/                    ASP.NET Core 平台服务
├─ adapter/                C# 海康适配服务
├─ sdk/hikvision/          设备网络 SDK_Linux64 原生库
├─ zlm/                    ZLMediaKit 配置和运行文件
├─ releases/               桌面端安装包
└─ logs/                   应用日志
```

systemd 服务至少包括：

```text
video-platform-api.service
hikvision-adapter.service
zlmediakit.service
postgresql.service
nginx.service
```

适配服务必须在 SDK 库目录可用、网络准备完成后再启动；停止服务时先停止媒体会话和报警布防，再注销设备并释放 SDK。

## 21．验收标准

### 21.1 功能验收

- 摄像头只在录像机侧配置，平台可以同步全部通道。
- 通道可以分配到机组，并在业务树中正确展示。
- 角色和账号只能访问授权通道。
- 单桌面端支持 4、9、16 路预览。
- 单桌面端支持多路回放。
- 支持播放、暂停、拖动、倍速和停止。
- 支持云台开始和停止控制。
- 已配置报警均能接收、保存和展示。
- 管理后台可以查看系统和设备统计。
- 桌面端版本可以发布、撤回和强制升级。

### 21.2 并发验收

- 100 个账号可以同时登录。
- 100 个客户端观看相同通道时，录像机只产生少量上游流。
- 多通道观看时，服务器出口带宽、CPU 和内存保持在安全阈值内。
- 至少完成 20 个独立回放会话测试，并记录设备实际上限。
- 报警可以同时推送给多个授权客户端。

### 21.3 安全验收

- 未授权通道的预览、回放、报警和 PTZ 请求均返回拒绝。
- 客户端无法获得录像机账号、密码和源地址。
- 权限撤销后已有媒体会话停止。
- PTZ 断线和失焦时自动停止。
- 所有权限和控制操作都有审计记录。

## 22．首阶段必须确认的问题

以下内容必须通过 DS-A72124R 实机确认：

1. 固件版本和 `设备网络SDK_Linux64 V6.1.11.30` 兼容性。
2. 实际通道数量和通道编号规则。
3. 主码流、子码流和 H.265 播放兼容性。
4. 最大实时预览路数。
5. 最大回放路数。
6. 报警回调能覆盖的事件类型和图片数据格式。
7. PTZ 摄像头通道和可用命令。
8. 录像回放码流发布到 ZLMediaKit 的具体方式。
9. 服务器与客户端之间的实际出口带宽。
10. Linux64 HCNetSDK 及相关播放库随产品分发的许可要求。
