# 第二版接口协作契约

本文用于并行实现的固定契约。对外接口前缀 `/api/v2`，JSON 使用 camelCase，时间统一为带时区 ISO 8601。所有通道操作使用数据库全局 `channelId`，只有适配器使用设备内通道号 `channel`。

## 公共格式与认证

- 分页：`{items: T[], total: number, page: number, pageSize: number}`，参数 `page=1&pageSize=50&search=`。
- 错误：`{code: string, message: string, traceId: string}`，401 未登录，403 无权限，409 冲突，429 超配额。
- `GET /auth/csrf` → `{token}`。Web 写请求携带 `X-CSRF-Token`，包括登录，使用 `credentials: include`。
- `POST /auth/login {username,password,clientType:'web'|'desktop',clientVersion}` → `{user,accessToken?,expiresAt}`；Web 仅 Cookie，桌面返回令牌。
- `POST /auth/refresh` → 同登录；`POST /auth/logout`；`GET /auth/me` → User。
- User：`{id,username,displayName,phone,status,permissions:string[],roleIds:number[]}`。
- `PUT /auth/profile {displayName,phone}`；`PUT /auth/password {currentPassword,newPassword}`。
- `GET /public/releases/latest` → Release 或 204，另保留旧 `/api/desktop-releases/latest` 与下载入口。

## 管理数据

- `GET /dashboard` → `{users,roles,devices,onlineDevices,channels,onlineChannels,alarmsToday,pendingAlarms,liveSessions,playbackSessions,onlineSessions}`。
- `GET /system` → `{cpuPercent,memoryTotalBytes,memoryUsedBytes,diskTotalBytes,diskFreeBytes,uptimeSeconds,services:[{name,status}],media:{liveSessions,playbackSessions,transcodes},version}`。
- `GET/POST /devices`，`GET/PUT/DELETE /devices/{id}`，`POST /devices/{id}/test`、`POST /devices/{id}/sync`。写入 `{name,host,port,username,password?,enabled}`；返回 `{id,name,host,port,username,enabled,status,model,serialNumber,lastSeenAt,channelCount,onlineChannels}`，密码不可读取。
- `GET /channels?deviceId=&unitId=&search=&online=` → 分页 Channel。Channel：`{id,deviceId,deviceName,deviceChannel,name,model,status,unitId,ptzCapable,codec?}`。
- `PUT /channels/assignment {channelIds:number[],unitId:number|null}`；`GET /organization` → `{workshops:Node[],areas:Node[],units:Node[]}`；Node：`{id,name,code,status,parentId?}`。`POST/PUT/DELETE /organization/{workshops|areas|units}[/{id}]`，写入 Node。
- `GET/POST /users`，`PUT /users/{id}`。写入 `{username,password?,displayName,phone,status,roleIds:number[]}`。
- `GET/POST /roles`，`PUT/DELETE /roles/{id}`。Role：`{id,name,code,status,permissionCodes:string[],userCount}`。
- `GET /permissions` → `[{code,name}]`；`PUT /roles/{id}/permissions {codes:string[]}`。
- `GET/PUT /scopes/{user|role}/{id}` → `{allChannels:boolean,scopes:[{type:'workshop'|'area'|'unit'|'channel',id:number}]}`。
- `GET /sessions` → 分页 `{id,userId,username,clientType,clientVersion,createdAt,lastSeenAt,expiresAt}`；`DELETE /sessions/{id}`。
- `GET /audit?search=&action=&from=&to=` → 分页 `{id,username,action,resource,summary,clientIp,createdAt}`。
- `GET/PUT /settings` → `{livePerUser,playbackPerUser,playbackPerDevice,playbackGlobal,transcodeGlobal,exportGlobal,exportPerDevice,exportRetentionDays,exportQuotaGb,alarmRetentionDays,auditRetentionDays}`。

## 值守与媒体

- `POST /live-sessions {channelId,streamType:1|2,profile:'native'|'browser'}` → LiveSession；`POST /live-sessions/{id}/renew`；`DELETE /live-sessions/{id}`。
- LiveSession：`{id,channelId,streamType,state,expiresAt,rtspUrl,httpFlvUrl,hlsUrl,codec,transcoded}`。
- `POST /recordings/search {channelId,start,end}` → `[{fileName,start,end,fileSize,fileType,streamType,fileIndex}]`。
- `POST /playback-sessions {channelId,start,end,profile}` → PlaybackSession；`GET /playback-sessions/{id}`；`POST /playback-sessions/{id}/renew`；`DELETE /playback-sessions/{id}`。
- PlaybackSession：LiveSession 加 `{start,end,currentTime,progress,speed,segments:[{start,end}]}`，state 为 `starting|playing|paused|gap|completed|failed|stopped`。
- `POST /playback-sessions/{id}/control {action:'pause'|'resume'|'seek'|'speed',position?:string,speed?:number}`。
- `POST /channels/{id}/ptz {command:'up'|'down'|'left'|'right'|'auto'|'zoomIn'|'zoomOut'|'focusNear'|'focusFar'|'irisOpen'|'irisClose',speed:1..7}`，每 2 秒同参数保活；`POST /channels/{id}/ptz/stop`；`POST /channels/{id}/ptz/presets/{preset}`。
- `GET /favorites` → Channel[]；`PUT /favorites {channelIds:number[]}`。
- `GET/POST /layouts`，`PUT/DELETE /layouts/{id}`。Layout：`{id,name,kind:'layout'|'patrol',shared,layout:1|4|9|16,intervalSeconds,channelIds:number[]}`。

## 报警、导出与发布

- `GET /alarms?state=&deviceId=&channelId=&eventType=&from=&to=&search=` → 分页 Alarm；`GET /alarms/{id}` → Alarm 加 `{history:[{id,action,note,username,createdAt}]}`。
- Alarm：`{id,deviceId,deviceName,channelId,channelName,eventType,occurredAt,state:'new'|'processing'|'closed',recovered,ownerId,ownerName,note,imageAvailable,payload}`。
- `POST /alarms/{id}/actions {action:'claim'|'note'|'close'|'reopen',note?}`；`GET /alarms/{id}/image` 返回图片。
- `GET/POST /exports`，创建 `{channelId,start,end}`，返回 `{id,channelId,channelName,start,end,state:'queued'|'running'|'completed'|'failed'|'cancelled',progress,error,fileName,fileSize,createdAt,expiresAt}`；`POST /exports/{id}/cancel`、`POST /exports/{id}/retry`，`GET /exports/{id}/download`。
- `GET /releases` → 分页 Release；`POST /releases` multipart 表单字段 file/version/releaseNotes/minimumVersion/forceUpdate；`POST /releases/{id}/publish {minimumVersion,forceUpdate}`、`POST /releases/{id}/revoke`、`GET /releases/{id}/download`。
- Release：`{id,version,fileName,sha256,fileSize,releaseNotes,minimumVersion,forceUpdate,status,publishedAt,downloadCount,downloadUrl}`。
- `/hubs/v2/events` 使用 Cookie 或桌面令牌，事件名 `alarm.changed`、`device.changed`、`media.changed`、`export.changed`、`access.changed`，消息 `{id,version,kind}`。接收后重新查询数据，断线恢复同样重新查询。

## 海康适配器内部接口

统一 `X-Adapter-Key`，仅回环监听，绝不外露。设备注册由平台完成。

- `GET /health`；`PUT /internal/devices/{deviceId} {host,port,username,password,enabled}`；`DELETE /internal/devices/{deviceId}`。
- `POST /internal/devices/{deviceId}/sync` → `{device:{model,serialNumber,...},channels:[{channel,name,model,online,ptzCapable,codec?}]}`。
- `POST /internal/devices/{deviceId}/live {sessionId,channel,streamType,profile}` → `{stream,streamType,codec,transcoded}`；`DELETE /internal/devices/{deviceId}/live/{sessionId}`。
- `POST /internal/devices/{deviceId}/recordings/search {channel,start,end}` → Recording[]。
- `POST /internal/devices/{deviceId}/playback {sessionId,userId,channel,start,end,profile}` → `{id,stream,state,start,end,currentTime,progress,speed,segments,codec,transcoded}`；`GET/DELETE /internal/devices/{deviceId}/playback/{sessionId}`；`POST /internal/devices/{deviceId}/playback/{sessionId}/control {action,position?,speed?}`。
- `POST /internal/devices/{deviceId}/ptz {channel,command,speed,stop}`；`POST /internal/devices/{deviceId}/ptz/preset {channel,preset}`。
- `POST /internal/devices/{deviceId}/exports {jobId,channel,start,end,outputDirectory}` → 立即返回任务状态；`GET/DELETE /internal/devices/{deviceId}/exports/{jobId}` → `{state,progress,path?,error?}`。路径位于平台导出目录，后台任务负责入库及下载。
- `GET /internal/sessions` 返回设备及媒体会话清单供重启核对；`GET /internal/devices/{deviceId}/events?after=&limit=100` → `{items:[{id,deviceId,channel?,eventType,occurredAt,recovered,payload,imageBase64?}],nextCursor}`，持久化分段日志，游标恢复；`POST /internal/devices/{deviceId}/events/ack {cursor}`。

## 实施纪律

仅用 apply_patch 修改源文件；禁止命令行改写代码。各实现者仅修改其负责目录。与其他工作相关的契约变动必须通知主实施者。所有文档、注释和用户可见消息使用简体中文。不得将模拟器结果记作真实设备验收。
